How NECO Mathematics rewards you

In the theory paper, marks are shared among method, accuracy and the final answer. That means a neat, line-by-line solution can earn marks even when you slip at the last step. A bare answer with no working can earn almost nothing. For every question below, notice how each line is a separate scoring point.

The question types here come up in many forms. Learn the method, then practise changing the numbers. Check the current NECO syllabus for the full topic list.

1. Quadratic equations by factorisation

The method: move everything to one side so it equals zero, find two numbers that multiply to (a x c) and add to b, split the middle term, factorise by grouping, then set each bracket to zero.

QuestionSolve 2x2 - 5x - 3 = 0
  1. a x c = 2 x (-3) = -6 and we need two numbers that multiply to -6 and add to -5, which are -6 and 1
  2. Split the middle term: 2x2 - 6x + x - 3 = 0
  3. Group: 2x(x - 3) + 1(x - 3) = 0
  4. Factorise: (2x + 1)(x - 3) = 0
  5. Set each bracket to zero: 2x + 1 = 0 or x - 3 = 0
Answerx = -1/2 or x = 3

Check: put x = 3 into the equation: 2(9) - 15 - 3 = 18 - 18 = 0. Correct. Always check one root. If the equation will not factorise, use the formula x = (-b plus or minus sqrt(b2 - 4ac)) / 2a.

2. Simultaneous equations

Two unknowns, two equations. The elimination method is usually fastest: make the coefficients of one letter equal, then add or subtract.

QuestionSolve 2x + y = 7 and x - y = 2
  1. Add the two equations so y cancels: (2x + x) + (y - y) = 7 + 2
  2. This gives 3x = 9 so x = 3
  3. Substitute x = 3 into x - y = 2: 3 - y = 2
  4. So y = 1
  5. Check in the first equation: 2(3) + 1 = 7 which is correct
Answerx = 3 and y = 1

In word problems, define your letters first: "Let the cost of a pen be x naira and a ruler be y naira." Then turn each sentence into an equation. Many candidates lose the first mark by skipping this definition.

3. Variation

Direct variation means y = kx. If y varies as x squared, write y = kx2. Inverse variation means y = k/x. The pattern never changes: write the relationship, find k with the first set of values, then use k.

Questiony varies directly as the square of x. If y = 18 when x = 3, find y when x = 5.
  1. Write the relation: y = kx2
  2. Substitute: 18 = k x 9 so k = 2
  3. Rewrite the law: y = 2x2
  4. Put x = 5: y = 2 x 25 = 50
Answery = 50

For joint variation (for example, y varies as x and inversely as z), write y = kx/z and proceed the same way. Common mistake: using the wrong power. If the question says "square of x", the power belongs to x, not to y.

4. Probability without replacement

Read the keywords. "Without replacement" means the number of items drops after the first draw. "And" usually means multiply; "or" means add (for events that cannot happen together).

QuestionA bag has 5 red, 3 blue and 2 green balls. Two balls are drawn one after the other without replacement. Find the probability that both are red.
  1. Total balls at the start = 5 + 3 + 2 = 10
  2. P(first red) = 5/10
  3. One red is gone, so 4 red remain out of 9 balls: P(second red) = 4/9
  4. Multiply: 5/10 x 4/9 = 20/90
AnswerProbability = 2/9

Always reduce your fraction, and remember a probability is never more than 1. If your answer is 1.3 or negative, go back and check.

5. Arc length and area of a sector

For a sector with angle theta and radius r, the arc length is (theta/360) x 2 x pi x r, and the area is (theta/360) x pi x r2. Use pi = 22/7 when the radius is a multiple of 7, as it makes the arithmetic clean.

QuestionA sector of a circle has radius 14 cm and angle 90 degrees. Find its arc length and area. Take pi = 22/7.
  1. Arc length = (90/360) x 2 x 22/7 x 14
  2. = 1/4 x 2 x 22/7 x 14 = 1/4 x 88 = 22 cm
  3. Area = (90/360) x 22/7 x 14 x 14
  4. = 1/4 x 22/7 x 196 = 1/4 x 616 = 154 cm2
AnswerArc length = 22 cm and area = 154 cm2

Common errors: giving the area in cm instead of cm2, and using the diameter in place of the radius. If the question gives the diameter, halve it first.

Mistakes that cost marks across all topics

  • Skipping lines: if you do three steps in your head and get the sign wrong, the examiner has nothing to credit.
  • Sign errors: when removing a bracket with a minus sign in front, change every sign inside it.
  • Not reading the instruction: "leave your answer in surd form" or "correct to 3 significant figures" is a mark by itself.
  • No units: include cm, cm2, naira or degrees where needed.
  • Ignoring the diagram: redraw it large in your answer and label the given values.

Time management

Do the questions you are sure of first. If a part takes more than a few minutes with no progress, move on and come back. Partial marks on five questions beat a perfect answer on one.

How to practise past questions properly

Do not just read solutions. Take one topic, attempt five questions under a timer without looking, then mark yourself using the method, not only the answer. Keep an error notebook: write the question, your mistake and the correction. Before the exam, re-read that notebook, because you tend to repeat the same errors.

What to do today

  • Solve three quadratic equations by factorisation and check each root
  • Solve two simultaneous equations by elimination
  • Write out the variation steps for one new question
  • Do two probability questions with and without replacement
  • Start an error notebook with today's mistakes

Frequently asked questions

How do I pass NECO Mathematics?

Practise past-question types until the methods are automatic, show every line of working, and revise the high-frequency topics first: algebra, number and numeration, geometry, mensuration, statistics and probability.

Do I get marks for working if my answer is wrong?

In the theory section, marks are generally awarded for correct method as well as final answers, so write each step clearly. Always show the formula you use and the substitution.

Which topics repeat most in NECO Mathematics?

Quadratic equations, simultaneous equations, variation, indices and logarithms, sets, mensuration, probability and statistics regularly feature. Check the current syllabus for the full list.

Can I use a calculator in NECO Mathematics?

Check the current NECO instructions for permitted calculators and mathematical tables. Even when allowed, practise without one so you can handle simple arithmetic quickly.
