Quadratic Equations: Factorisation, Formula and Completing the Square, All Solved

Three methods, one equation type. See how to solve quadratics by factorisation, by the formula and by completing the square, and how to know which method to pick.

What a quadratic equation looks like

A quadratic equation has the form ax2 + bx + c = 0, where a, b and c are numbers and a is not zero. It has up to two solutions, called roots. Before you use any method, always rearrange so that everything is on one side and zero is on the other.

⚠️
Check first

If the question gives x2 + 5x = -6, move the -6 across to get x2 + 5x + 6 = 0 before factorising.

Method 1: factorisation

Find two numbers that multiply to give ac and add to give b.

QuestionSolve x2 + 5x + 6 = 0.
  1. Find two numbers with product 6 and sum 5: they are 2 and 3
  2. Write (x + 2)(x + 3) = 0
  3. Either x + 2 = 0 or x + 3 = 0
Answerx = -2 or x = -3

When a is not 1, split the middle term. Solve 3x2 + x - 2 = 0. Here ac = -6 and b = 1, so the numbers are 3 and -2. Write 3x2 + 3x - 2x - 2 = 0, then 3x(x + 1) - 2(x + 1) = 0, which gives (3x - 2)(x + 1) = 0. So x = 2/3 or x = -1. Check x = -1: 3 - 1 - 2 = 0. Correct.

Method 2: the quadratic formula

When factorisation is not obvious, use the formula, which always works.

Quadratic formulax = (-b +/- sqrt(b2 - 4ac)) / 2aa is the coefficient of x squared, b of x, and c is the constant
QuestionSolve 2x2 - 3x - 5 = 0.
  1. a = 2, b = -3, c = -5
  2. Discriminant = (-3)2 - 4(2)(-5) = 9 + 40 = 49
  3. sqrt(49) = 7
  4. x = (3 + 7)/4 = 10/4 = 2.5 or x = (3 - 7)/4 = -1
Answerx = 5/2 or x = -1

Another example where the answer is not neat: solve x2 - 4x - 3 = 0. The discriminant is 16 + 12 = 28, so x = (4 +/- sqrt(28))/2 = 2 +/- sqrt(7). To 2 decimal places, x = 4.65 or x = -0.65. When the question says leave your answer in surd form, stop at 2 +/- sqrt(7).

Careful with signs: with b = -3, the term -b becomes +3. Put negative numbers in brackets when you square them.

Method 3: completing the square

The idea: add the square of half the coefficient of x to both sides so the left side becomes a perfect square.

QuestionSolve x2 + 6x - 7 = 0 by completing the square.
  1. Move the constant: x2 + 6x = 7
  2. Half of 6 is 3 and 3 squared is 9, so add 9 to both sides: x2 + 6x + 9 = 16
  3. Write (x + 3)2 = 16
  4. Take square roots: x + 3 = 4 or x + 3 = -4
Answerx = 1 or x = -7

If the coefficient of x2 is not 1, divide the whole equation by it first. For 2x2 + 8x - 10 = 0, divide by 2 to get x2 + 4x - 5 = 0, then x2 + 4x + 4 = 9, so (x + 2)2 = 9 and x = 1 or x = -5.

The discriminant and roots

The expression b2 - 4ac decides what kind of roots you get.

  • Greater than 0: two different real roots.
  • Equal to 0: two equal roots (one repeated root).
  • Less than 0: no real roots.

For x2 - 6x + 9 = 0, the discriminant is 36 - 36 = 0, so there are equal roots, x = 3.

Sum and product of roots, and forming equations

If the roots are p and q, then p + q = -b/a and pq = c/a. To form an equation with roots 2 and -3: sum = -1 and product = -6, so x2 - (-1)x + (-6) = 0, which is x2 + x - 6 = 0. Check by factorising: (x - 2)(x + 3) = x2 + x - 6. Correct.

Common mistakes

  • Forgetting to set equation to zero
  • Losing the minus in -b
  • Giving only one root

Better habits

  • Rearrange first
  • Bracket negatives
  • Always give both roots and check

Frequently asked questions

What is a quadratic equation?

It is an equation that can be written as ax2 + bx + c = 0, where a is not zero.

Which method should I use in the exam?

Try factorisation first because it is fastest. If it does not factorise easily, use the formula. Use completing the square when the question specifically asks for it.

What does the discriminant tell you?

The value b2 - 4ac. If positive there are two real roots, if zero there is one repeated root, and if negative there are no real roots.

How do I form a quadratic equation from its roots?

Use x2 - (sum of roots)x + (product of roots) = 0.
