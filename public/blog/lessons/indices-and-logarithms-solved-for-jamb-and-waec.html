Indices and Logarithms Made Easy, With Solved JAMB and WAEC-Style Questions

Indices and logarithms are two sides of the same idea. Learn the laws, see them applied in solved questions, and avoid the slips that cost marks.

The laws of indices

An index (or power) tells you how many times a number is multiplied by itself. In 25, the base is 2 and the index is 5, so it equals 2 x 2 x 2 x 2 x 2 = 32. These laws apply when the bases are the same:

  • am x an = am+n
  • am / an = am-n
  • (am)n = amn
  • a0 = 1 (for a not zero)
  • a-n = 1 / an
  • a1/n = nth root of a, and am/n = (nth root of a)m
🔑
Golden rule

The laws only work when the bases are the same. Change bases first, for example write 4 as 22 and 8 as 23.

Solved questions on indices

QuestionEvaluate 82/3 and 27-2/3.
  1. 8 = 23, so 82/3 = (cube root of 8)2 = 22 = 4
  2. 27 = 33, so 272/3 = 32 = 9
  3. The negative index inverts: 27-2/3 = 1/9
Answer82/3 = 4 and 27-2/3 = 1/9
QuestionSolve 2x+1 = 32.
  1. Write 32 as a power of 2: 32 = 25
  2. Equal bases means equal indices: x + 1 = 5
Answerx = 4

Now try a harder one. Simplify (23 x 42) / 8. Write everything as powers of 2: 42 = 24, and 8 = 23. The expression becomes (23 x 24) / 23 = 27 / 23 = 24 = 16.

Some questions hide a quadratic. Solve 52x - 6(5x) + 5 = 0. Let y = 5x. Then y2 - 6y + 5 = 0, so (y - 1)(y - 5) = 0 and y = 1 or y = 5. Since 5x = 1 gives x = 0 and 5x = 5 gives x = 1, the answers are x = 0 or x = 1.

From indices to logarithms

A logarithm answers the question: what power do I raise the base to in order to get this number? If 25 = 32, then log2 32 = 5. In general, ax = N means loga N = x.

1Index form 10 squared = 100
2Same fact as log form
3log base 10 of 100 = 2

Useful values: loga 1 = 0 and loga a = 1. When no base is written, the base is 10 in most school textbooks.

The laws of logarithms

Log lawslog(AB) = log A + log B ; log(A/B) = log A - log B ; log(An) = n log AThe base must be the same on every term

These come directly from the index laws, because a logarithm is an index.

QuestionEvaluate log2 8 + log2 4, and log 5 + log 20 (base 10).
  1. log2 8 = 3 because 23 = 8
  2. log2 4 = 2 because 22 = 4
  3. Sum = 5
  4. log 5 + log 20 = log(5 x 20) = log 100 = 2
AnswerThe answers are 5 and 2

Solving logarithm equations

Solve logx 81 = 4. Convert to index form: x4 = 81 = 34, so x = 3 (the base must be positive).

Solve log2 (x + 3) = 4. Then x + 3 = 24 = 16, so x = 13. Always check that the number inside the log is positive: 13 + 3 = 16, which is fine.

For an equation like 3x = 20 where bases cannot be matched, take logs of both sides: x log 3 = log 20, so x = log 20 / log 3. With a calculator or tables, log 20 is about 1.3010 and log 3 about 0.4771, so x is about 2.73.

Common slips to avoid

  • Writing log(A + B) = log A + log B. It is false. The law works for products, not sums.
  • Adding indices when bases differ, such as 23 x 32.
  • Forgetting that a negative index means a reciprocal, not a negative number.
  • Skipping the check that a logarithm argument is positive.

What to do today

  • Write the six index laws and three log laws from memory
  • Convert five index statements into log form and back
  • Solve two equations by matching bases
  • Solve one equation that hides a quadratic
  • Do one log equation and check the argument is positive

Frequently asked questions

What are the laws of indices?

am x an = am+n, am / an = am-n, (am)n = amn, a0 = 1, a-n = 1/an, and a1/n is the nth root of a.

How are indices and logarithms related?

If ax = N, then log base a of N = x. A logarithm is simply the index.

What is log 1 and what is log of the base?

log of 1 to any base is 0, and log of a number to its own base is 1.

Can you take the log of a negative number?

Not in real numbers. The number inside a log must be positive.
